一条指令的旅程

  1. 1 · 现在看见“星星在右边”

    根据位置和速度，决定向右推多少。

  2. 2 · 排队等待“新指令还没到”

    飞船继续滑行，旧指令还在执行。

  3. 3 · 终于生效“位置已经变了”

    新指令按原计划执行，却可能已经推得太晚。

  4. 4 · 再次纠正“这次往左推”

    纠正也要等待。用力过大时，就可能反复追过头。

01 / 反馈

边看边改

发现星星在右边，就向右推；发现自己冲得太快，就刹车。“观察 → 调整 → 再观察”就是反馈。你调淋浴水温时，也在做类似的事。

02 / 延迟

修正来晚了

你刚刚想向右推，但飞船过一会儿才收到指令。等它收到时，你可能已经需要向左推了。越用力纠正，越可能来回追过头。

03 / 预测

先想一想将来的位置

紫色飞船会根据当前速度和排队中的指令，估计新指令生效时的位置。它还假设星星会暂时保持当前速度。突然转向时，这个猜测也会错。
