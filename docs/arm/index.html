把试玩变成自己的发现

01 / GEOMETRY

先问：够得着吗？

两根手臂长度固定。星星超出范围时，再着急也抓不到。关节角度受限时，同一种弯肘姿势也可能到不了。

02 / FEEDBACK

再问：停得下来吗？

只看位置，容易越过目标再折返。加上速度反馈，就像提前松油门、踩刹车。但刹车太强也可能变慢。

03 / DELAY

最后问：来得及吗？

指令排队时，机械臂仍在运动。迟到的刹车也可能让它来回摆动：PD 不保证在所有延迟下都更好。

  1. 选“抓过头了”，只调整刹车强度，比较完整成绩。
  2. 选“指令来晚了”，只把延迟改为 0，再保存一局。
  3. 把星星拖出圆环，再拖回里面。为什么调参数不能解决所有失败？
