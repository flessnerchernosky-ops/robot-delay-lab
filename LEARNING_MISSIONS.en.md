# A 15-minute path through Star Chase

[中文](LEARNING_MISSIONS.md) · [English](LEARNING_MISSIONS.en.md) · [Play](https://flessnerchernosky-ops.github.io/robot-delay-lab/?lang=en)

1. **Minutes 0–3:** run Gentle approach. Observe position and velocity. Why does releasing thrust not stop motion instantly?
2. **Minutes 3–6:** select More push, more wobble. Write a hypothesis, finish all 20 seconds, save the scores and download CSV.
3. **Minutes 6–9:** select Learn to brake. Only braking changes from the previous preset. Complete and save this run, then compare. Explain whether the observations support your hypothesis.
4. **Minutes 9–12:** select Prediction can fail. Observe a counterexample to “prediction is always better”. Its target and parameters differ from the previous run, so this is not a single-variable parameter comparison.
5. **Minutes 12–15:** download your notes. Record the settings, complete-run scores, model assumptions and one next question. Distinguish your own experiments from included presets.

For a new controlled comparison, start from one preset and change only delay, gain or braking, with manual driving off and the same automatic target. Repeat identical settings to check determinism; do not call repeated deterministic runs independent random trials.

Notes persist only in the current page. Download them before refreshing or closing. See the [model guide](EPISODE_02.en.md) for scoring and limitations.
